# HR Management Saudi

نظام إدارة موارد بشرية مخصص لبيئة العمل السعودية.

## المرحلة الأولى
- Dashboard
- قاعدة بيانات الموظفين
- استيراد بيانات Excel
- ملف الموظف
- إدارة الإقامة والجواز ورخصة العمل
- التأمين الطبي
- التأمينات الاجتماعية
- التنبيهات ومواعيد الانتهاء
- التقارير
- بنية جاهزة للرواتب وWPS

## التقنية
React + TypeScript + Vite

> هذا المشروع قيد التطوير ولا يُعد بحد ذاته استشارة قانونية. يجب مراجعة الإعدادات والنسب والنماذج مع آخر المتطلبات الرسمية قبل التشغيل الإنتاجي.
