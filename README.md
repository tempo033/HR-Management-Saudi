# HR Management Saudi

نظام إدارة موارد بشرية مخصص لبيئة العمل السعودية.

## المرحلة الحالية
- Dashboard
- قاعدة بيانات الموظفين
- استيراد وتصدير Excel
- ملف الموظف
- إدارة الإقامة والجواز ورخصة العمل
- التأمين الطبي
- التأمينات الاجتماعية
- مسير الرواتب
- WPS / SIF
- النماذج الإلكترونية القابلة للتحرير والحفظ والطباعة
- التقارير
- إعدادات التنبيهات ونسب GOSI

## التقنية
React + TypeScript + Vite

> المشروع قيد التطوير. قبل التشغيل الإنتاجي يجب ربط قاعدة بيانات مركزية وصلاحيات وسجل تدقيق ونسخ احتياطي، ومراجعة المتطلبات السعودية الرسمية الحالية.
