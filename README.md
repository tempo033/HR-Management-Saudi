# HR Management Saudi

نظام إدارة موارد بشرية مخصص لبيئة العمل السعودية، بواجهة عربية RTL، ويعمل بدون خدمات مدفوعة في التشغيل الأساسي.

## المميزات الحالية
- Dashboard ومؤشرات الموظفين والتنبيهات
- قاعدة بيانات الموظفين والبحث والاستيراد/التصدير عبر Excel
- تعديل بيانات الموظف وحفظها محلياً
- ملف موظف شامل للبيانات الوظيفية والمالية والبنكية
- إدارة الإقامة والجواز ورخصة العمل والتأمين الطبي
- التأمينات الاجتماعية GOSI مع نسب قابلة للضبط من إعدادات النظام
- مسير رواتب تفصيلي مع حفظ بيانات الموظفين داخل كل مسير وتصدير CSV
- WPS / SIF تمهيدي مع فحص IBAN السعودي وتصدير Excel/CSV
- مركز جودة بيانات لاكتشاف الحقول المفقودة وأرقام الموظفين المكررة وIBAN غير الصحيح
- الحضور والانصراف حسب التاريخ مع الحفظ والتصدير
- الإجازات مع حساب الأيام ومنع التداخل بين الإجازات المسجلة
- النماذج الإلكترونية القابلة للتحرير والحفظ والطباعة
- نموذج مباشرة العمل مع إخفاء الحزمة المالية عندما لا تكون الحالة «تعيين جديد»
- تسجيل الحركة الوظيفية: ترقية، نقل، تعديل راتب وتغيير المسمى/الإدارة
- إدارة العقود: النوع، البداية، النهاية، فترة التجربة، الإشعار، التجديد والتنبيهات
- تنبيهات العقود المنتهية والقريبة من الانتهاء
- سجل تدقيق محلي للإجراءات الإدارية المطورة
- أدوار استخدام محلية: مسؤول النظام، الموارد البشرية، الرواتب، المدير، قراءة فقط
- نسخة احتياطية واستعادة كاملة بصيغة JSON مع إنشاء نسخة أمان قبل الاسترجاع
- التقارير وإعدادات التنبيهات ونسب GOSI
- GitHub Actions لفحص `npm run build` تلقائياً عند كل Push وPull Request

## حماية البيانات بدون خدمات مدفوعة
النسخة الحالية تعمل محلياً داخل المتصفح باستخدام `localStorage`، مع إمكانية تنزيل واستعادة نسخة احتياطية JSON. لا توجد قاعدة بيانات أو API مدفوع مطلوب للتشغيل الأساسي.

## حدود النسخة المحلية
- الأدوار الحالية لتنظيم الواجهة وليست نظام مصادقة أو أمان إنتاجي.
- البيانات مرتبطة بالمتصفح والجهاز ما لم يتم نقلها عبر النسخة الاحتياطية.
- WPS / SIF الحالي تصدير تمهيدي ويجب مطابقته مع مواصفات البنك/مدد قبل الاعتماد الرسمي.
- نسب GOSI قابلة للضبط ويجب مراجعة الفئة والنسب الفعلية لكل حالة قبل الاعتماد المحاسبي.
- قبل التشغيل متعدد المستخدمين يلزم Backend وقاعدة بيانات مركزية ومصادقة وصلاحيات حقيقية وتشفير ومراجعة متطلبات الامتثال الحالية.
