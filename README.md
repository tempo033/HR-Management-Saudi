# HR Management Saudi

نظام إدارة موارد بشرية مخصص لبيئة العمل السعودية، بواجهة عربية RTL.

## المميزات الحالية
- Dashboard ومؤشرات الموظفين والتنبيهات
- قاعدة بيانات الموظفين والبحث والاستيراد/التصدير عبر Excel
- تعديل بيانات الموظف وحفظها محلياً
- ملف الموظف والبيانات الوظيفية والمالية والبنكية
- إدارة الإقامة والجواز ورخصة العمل والتأمين الطبي
- التأمينات الاجتماعية مع نسب قابلة للضبط
- ملخص مسير الرواتب: الاستحقاقات، اشتراك الموظف، الصافي التقديري وحصة صاحب العمل
- WPS / SIF
- النماذج الإلكترونية القابلة للتحرير والحفظ والطباعة
- تسجيل الحركة الوظيفية: ترقية، نقل، تعديل راتب وتغيير المسمى/الإدارة
- سجل تدقيق محلي للإجراءات الأساسية
- نسخة احتياطية واستعادة مجانية بصيغة JSON
- التقارير وإعدادات التنبيهات ونسب GOSI

## حماية البيانات بدون خدمات مدفوعة
النسخة الحالية تعمل محلياً داخل المتصفح باستخدام `localStorage`، مع إمكانية تصدير نسخة احتياطية JSON. لا توجد خدمة مدفوعة أو API خارجي مطلوب للتشغيل الأساسي.

## التقنية
React + TypeScript + Vite + XLSX + Lucide React

## التشغيل
```bash
npm install
npm run dev
```

ولبناء نسخة الإنتاج:
```bash
npm run build
```

> المشروع قيد التطوير. قبل الاستخدام الإنتاجي متعدد المستخدمين يجب إضافة قاعدة بيانات مركزية وصلاحيات حقيقية وتشفير/إدارة أسرار ومراجعة قانونية لمتطلبات المملكة العربية السعودية الحالية.
